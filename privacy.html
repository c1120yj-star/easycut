easycut Privacy Policy

Last updated: November 15, 2026

easycut is a personal tool used only by its owner on the owner's own computer, to upload and manage videos on YouTube channels the owner runs. This policy explains what data it touches.

Data we access

When the owner connects a YouTube channel through Google sign-in, easycut receives an OAuth token for that channel. With it, easycut uses YouTube API Services to upload videos, set video details and thumbnails, change publish times, and read the channel's own video list and analytics (such as view counts).

How the data is used

The data is used only to upload the owner's videos and to show the owner how those videos perform. It is not used for advertising, not sold, and not shared with anyone.

Where the data is stored

OAuth tokens and video information are stored only on the owner's own computer. easycut has no server and does not send this data anywhere except to Google's own APIs.

Removing access

Access can be removed at any time at Google Account → Third-party connections. Deleting easycut's local data folder removes all stored tokens.

YouTube and Google

easycut uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy. easycut's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
