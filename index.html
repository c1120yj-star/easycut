easycut

A personal video tool for the owner's own YouTube channels

easycut is a private desktop tool that runs only on its owner's own computer. The owner uses it to edit short videos and upload them to YouTube channels that the owner runs. It is not offered to the public and has no other users.

With the owner's consent, easycut uses the YouTube Data API and the YouTube Analytics API to:

  • upload the owner's videos and set their title, description, thumbnail and publish time;
  • read the owner's own channel and video information and view counts, to plan the next upload.

Read how data is handled in the Privacy Policy.
